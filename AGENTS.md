# Research working rules

Write all new repository filenames, documentation, code comments, and commit messages in English. Preserve existing scientific evidence byte for byte. Keep Korean originals, machine paths, raw logs, large arrays, and model weights in the private archive and cite their SHA256 and object references.

This repository starts from a historical, sealed snapshot. Work underway in the older shared workspace is excluded. The coordinating parent task must review and arrange a handoff before a research chat changes its working directory. Do not interrupt another research process or copy a partially written run as a completed result.

Use fresh experiment directories. Record the source commit, configuration, environment, failures, complete outputs, and hashes before drawing conclusions. Do not rerun historical orchestration scripts against original paths. Do not claim new novelty, independent replication, race freedom, or performance from this repository setup.

Keep the repository private. Never commit credentials or personal machine paths. Existing archive credentials remain outside Git. The two paper prefixes organize objects within the same private bucket; they are not separate access boundaries. The shared limits remain 60 GB total storage, USD 5 monthly, and USD 5 initial upload/restore, across both papers and the existing archive.

Follow docs/tag_policy.md. No submission or acceptance tag, release, publication, submission, paid compute, or scheduled automation is authorized by the initial setup.
